# REDBEAM accessibility and readability review

Reviewer persona: WCAG 2.2 AA specialist; Windows high-contrast and text-scaling user; keyboard-only; low vision / colour-vision deficiency; 4K at 150% scaling; a 55-year-old estimator with reading glasses on a bright job-site laptop.

Method: eleven 3840x2088 screenshots (150% scaling, so 1 CSS px = 1.5 image px) inspected at 1:1 crops. Every contrast ratio below was **measured** from the pixels (most-common colour = background, median of the far-luminance tail = text) with the WCAG relative-luminance formula, not estimated. Sizes are reported in CSS px. Static screenshots cannot show focus order, tooltips, accessible names, Windows high-contrast rendering or Windows text-scaling behaviour; where a finding depends on those it is marked **verify**.

Recurring palette (for reference): app ground `#191918`, card `#232323`, raised `#35383C` / `#3E4146`, primary text `#F1F3F4`, secondary text `#B8BDC3` (9.3:1 on ground), tertiary text `#93979C` (6.0:1 on ground, 5.35:1 on card, 4.0:1 on raised), quaternary text `#6D7175` (3.6:1 on ground), accent `#4CC2FF`.

Severity scale: **blocker** = a user in the persona cannot complete or safely complete a task; **major** = fails an AA criterion or a Windows guideline in a way that hurts daily use; **paper cut** = passes or borderline, but costs the persona effort every time.

## 1. d1.png - Start screen

1. **WHERE:** `rename` / `forget` / `remove data` on each Recent row. **WHAT:** Three inline text links, ~13 px tall, 10 px apart, with the destructive `remove data` styled identically to `rename`. Target height is well under 24 px; the only thing keeping it inside the SC 2.5.8 spacing exception is the 38 px row pitch. A slip on a laptop trackpad lands on `forget` or `remove data`. **WHICH:** SC 2.5.8 Target Size (Minimum); SC 3.3.4 Error Prevention (data); Windows: destructive actions need distinct affordance + confirmation. **PROPOSED:** Replace with a row overflow button (`...`, 32x32) opening a menu; style `Remove data...` as destructive (red text or trailing warning icon) and always confirm with a dialog naming the folder and what is deleted. **SEVERITY:** major.
2. **WHERE:** Recent project row (title + path). **WHAT:** No visible affordance that the row itself opens the project (no button styling, no chevron, no hover state visible), and no visible keyboard path to it. **WHICH:** SC 2.1.1 Keyboard; SC 2.4.7 Focus Visible; Windows: discoverability. **PROPOSED:** Render each recent item as a real `button`/`listitem` with a full-row hover/focus rectangle, a leading folder icon and trailing `Open` chevron; make Tab land on the first recent item after the two primary buttons. **verify** with keyboard. **SEVERITY:** major.
3. **WHERE:** Whole screen. **WHAT:** No focus indicator is visible on any element. Either nothing has focus on launch (keyboard user has to Tab blindly) or the ring is invisible against the dark card. **WHICH:** SC 2.4.7 Focus Visible; SC 2.4.11 Focus Not Obscured; SC 2.4.13 Focus Appearance (AAA, but Windows Fluent expects a 2 px ring). **PROPOSED:** Auto-focus `Open a drawing set...` on launch; 2 px `#4CC2FF` outline with 2 px offset on every focusable control (already used on the prompt input in d4 - reuse that). **verify**. **SEVERITY:** major.
4. **WHERE:** Path line under each recent project (`C:\Users\aaron\Maxxit Grou...Ramp\Bentall Towers 1 & 2`). **WHAT:** Monospace ~11.5 px, tertiary grey 5.35:1, *middle-ellipsised* and then wrapped onto two lines anyway - so the reader loses the distinguishing folder and still pays for two lines. **WHICH:** SC 1.4.3 (passes, barely); SC 1.4.4 Resize Text (text this small will be first to fail at 125% text scaling); readability. **PROPOSED:** 13 px minimum, end-ellipsis only, tooltip/`title` with the full path, and let the path wrap to two full lines instead of truncating. **SEVERITY:** paper cut.
5. **WHERE:** `Open a project folder...` (secondary button) border. **WHAT:** Border `#44474C` on card `#232323` = **1.70:1**. The button's boundary is the only thing separating it from the card. **WHICH:** SC 1.4.11 Non-text Contrast (3:1 for component boundaries). **PROPOSED:** Border `#6D7175` or lighter (3.2:1), or fill the button `#35383C`. Apply to every secondary/outline button in the app (`Browse...`, `Create & open`, `Add scope`, `Set on the sheet`, `Reset all`). **SEVERITY:** major.
6. **WHERE:** Tagline `Quantity takeoff from construction drawings.` and hint `REDBEAM writes one redbeam.db beside the drawings and never modifies them.` **WHAT:** 13 px tertiary grey at 5.35:1. Passes AA, but the hint is the one sentence a new user must trust before pointing the app at a client folder; on a bright laptop it disappears. **WHICH:** SC 1.4.6 Contrast (Enhanced) as target (7:1); readability. **PROPOSED:** Hint in secondary `#B8BDC3` (8.3:1) at 14 px. **SEVERITY:** paper cut.
7. **WHERE:** Title-bar window controls (top right). **WHAT:** Custom-drawn minimise/restore/close glyphs ~10 px, thin, tertiary grey. Standard Windows caption buttons are 46x32 with system-theme glyphs and respond to high-contrast themes; custom ones frequently do not. **WHICH:** Windows: caption controls; SC 1.4.11; SC 2.5.8. **PROPOSED:** Keep hit areas >= 46x32 (**verify**), glyphs at least `#B8BDC3`, and make sure they follow `forced-colors` (`SystemCaptionText`). **SEVERITY:** paper cut.
8. **WHERE:** `Open a folder by path instead` link. **WHAT:** Underlined (good - not colour-only), but it is the only path for network/UNC folders and is placed as an afterthought below the list; 13 px. **WHICH:** Discoverability. **PROPOSED:** Promote to a third button `Open by path...` in the button row. **SEVERITY:** paper cut.
9. **WHERE:** Whole card, 437x300 CSS px centred in a 2560x1392 viewport. **WHAT:** The card does not appear to scale with the window; at Windows text scaling 125-150% (Settings > Accessibility > Text size) the two-column path/date/links row will overflow. **WHICH:** SC 1.4.4; SC 1.4.10 Reflow. **PROPOSED:** Card `max-width: 40rem` in rem units, links row allowed to wrap under the path. **verify** at 150% text size. **SEVERITY:** paper cut.

## 2. d2.png - Start screen, "Open a folder by path" expanded
